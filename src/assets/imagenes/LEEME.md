# Fotos del sitio

Guardá acá las fotos con **exactamente** estos nombres. Apenas el archivo
existe, reemplaza solo al bloque con iniciales. No hay que tocar nada más.

| Archivo                         | Dónde se ve              | Tamaño sugerido        |
| ------------------------------- | ------------------------ | ---------------------- |
| `dra-eva-herrera-bravo.jpg`     | Sobre mí (retrato)       | 1600 × 2000 px, vertical |
| `equipo/martin-quiroga.jpg`     | Equipo                   | 1000 × 1250 px, vertical |
| `equipo/lucia-benedetti.jpg`    | Equipo                   | 1000 × 1250 px, vertical |
| `equipo/carolina-mendez.jpg`    | Equipo                   | 1000 × 1250 px, vertical |
| `equipo/tomas-ferreyra.jpg`     | Equipo                   | 1000 × 1250 px, vertical |
| `equipo/paula-gimenez.jpg`      | Equipo                   | 1000 × 1250 px, vertical |

- Proporción vertical 4:5. Si la foto tiene otra proporción, se recorta al centro.
- Pueden ser en color: el sitio las pasa a blanco y negro.
- Formatos admitidos: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`.
- Si cambiás el nombre de un integrante, cambiá también el nombre del archivo
  en `src/data/equipo.ts` (campo `foto`).
- El sitio genera solo las versiones livianas para celular y escritorio.
